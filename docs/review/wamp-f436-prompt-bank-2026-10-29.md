# Approved automatic Build Prompt rotation — 2026-10-30

These 26 prompts rotate weekly when no manual prompt is scheduled. They are
creative briefs, using the existing voluntary prompt rules. Jonathan approved all 26 prompts as written on 2026-10-30. Automatic scheduling
was already approved.
Manual edits and deletions will remain available before the first entry.

1. **One Screen Wonder** — Build a complete challenge inside one room. Give it a clear start, a satisfying finish and at least one surprising detail.
2. **Spare Change** — Make coins guide the player through a room without enemies. Use their placement to teach the route.
3. **The Long Way Round** — Make the route bend back on itself before the finish. Let the player see somewhere they will reach later.
4. **Going Up** — Build a challenge about climbing. Use platforms, ladders or both, and make the top feel worth reaching.
5. **No Enemies Needed** — Create a fun challenge with no enemies. Let terrain, movement and the goal do the work.
6. **Soft Landing** — Build around careful landings. Give the player a safe place to learn before asking for a trickier jump.
7. **Moving Day** — Use a moving platform as an important part of the route. Make its purpose clear before the player needs it.
8. **Tiny Maze** — Make a small maze with readable clues. Reward paying attention rather than guessing.
9. **Two Ways Home** — Offer two different routes to the same finish. Make both worth trying.
10. **After Dark** — Give a room a nighttime mood. Keep the route readable while making the background and scenery do some storytelling.
11. **Forest Walk** — Build a woodland adventure. Use trees or forest scenery to frame the route without hiding important jumps.
12. **Underground** — Create a cave or tunnel challenge. Use open space and tight passages to change its rhythm.
13. **Desert Detour** — Build a desert room with an unexpected detour. Make the alternative route easy to notice but interesting to explore.
14. **Treasure Trail** — Make a trail of collectibles that leads through a room. Add one optional reward for a curious player.
15. **Door Policy** — Make a door or trapdoor matter to the route. Give the player a clear clue about how it opens.
16. **Switch It Up** — Use a switch or pressure plate to change the route. Let the player see what their action changed.
17. **Hidden in Plain Sight** — Include an optional secret that can be spotted with a good look. Keep the main route understandable without finding it.
18. **Up and Down** — Make the route change height several times. Use those changes to create a clear beginning, middle and end.
19. **Room to Breathe** — Build a relaxed room with room to explore. Leave space between challenges and make the setting enjoyable to visit.
20. **Five Platforms** — Create a challenge using no more than five separate landing platforms. Make each landing count.
21. **Welcome Mat** — Make a room for a brand-new player. Introduce one idea gently, then give them a chance to use it.
22. **The Scenic Route** — Create a journey worth looking at. Add scenery that supports the room’s theme while keeping the play path clear.
23. **Final Sprint** — Build a short race to the finish. Make the route readable enough that a second attempt can be faster.
24. **Mirror Moves** — Use a repeated or mirrored shape in the terrain. Change one detail so the second half asks the player to pay attention.
25. **Small Surprise** — Start with a simple, welcoming room and include one playful twist. Give a fair clue before the twist matters.
26. **Encore** — Take one idea from an earlier room you built and give it a new ending. Make the whole challenge work for someone seeing it for the first time.
