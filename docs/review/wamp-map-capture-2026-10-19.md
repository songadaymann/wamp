## Cost and idle review before deployment

The new coordinator is stored data, not a continuously executing process. D1 has no hourly capacity charge when no queries run. Its new records are indexed, bounded and maintained during capture requests. Existing daily scheduling stays unchanged. [D1 pricing](https://developers.cloudflare.com/d1/platform/pricing/).

Browser work remains finite. Assuming Cloudflare honors its documented default60-second idle closure after a disconnected/failed cleanup, a conservative allowance is180 browser-seconds per allowed start.310 starts across31 Eastern days represent up to15.5 hours, plus a small billing-boundary tail. Cloudflare rounds account-wide browser time to whole hours. On the paid schedule, if this is the only browser usage,16 rounded hours minus10 included hours is about$0.54. If shared allowances are already consumed, the corresponding marginal browser-time allowance is about$1.44. One added daily concurrency peak could add up to$2/month if the shared10-browser allowance is already exhausted. These are conservative planning cases, not a measured invoice or a claim that this account's allowance is unused. [Browser Run pricing](https://developers.cloudflare.com/browser-run/pricing/), [idle/session limits](https://developers.cloudflare.com/browser-run/limits/).

Existing account-wide R2 storage and rounded operation charges still apply. Streaming changes memory behavior while retaining one object read per archived file; it adds no periodic download or background reads.
