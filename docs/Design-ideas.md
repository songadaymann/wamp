
## Visual Style

- Use a flat, bold, retro game feel. Avoid glassmorphism, soft blur, and generic gradient-heavy UI.
- Pull highlight colors from the active tileset or the established game palette instead of inventing a separate UI palette [ref: https://lospec.com/palette-list/super-colorful-3]
- Different button states should be clearly different shapes or fills, not just opacity variants.
- Outer structural frames should use neutral contrast colors like white unless a strong accent is truly needed.
- Use the fonts we have, to give the UI personality.
